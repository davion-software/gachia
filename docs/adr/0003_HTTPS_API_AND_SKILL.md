# Integrar primero mediante una API HTTPS y una skill

Gachia expondrá una API HTTPS autenticada y una skill enseñará a Grok Bot a utilizarla desde su terminal. Frente a construir primero una integración MCP, esta interfaz también permite atender a otros agentes y a la futura app; MCP queda para después. La documentación de Grok Bot confirma terminal y skills, pero la compatibilidad efectiva seguirá pendiente hasta registrar y consultar un gasto desde el bot real del usuario.

Fuentes consultadas el 27 de octubre de 2026: [ordenador y aplicaciones](https://docs.x.ai/grok-bot/computer-and-apps) y [skills y rutinas](https://docs.x.ai/grok-bot/skills-routines-and-automations).
